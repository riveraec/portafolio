etl-reportes

Pipeline ETL de movimientos/KPIs.

Lee CSV, limpia y valida con pandas, carga a SQLite y genera un resumen diario por fecha y categoría. Idempotente por lote (fuente): reprocesar el mismo archivo no duplica filas.

Capa HTTP sobre el ETL.

eventos-api

GitHub Actions

Ingesta de webhooks sin duplicar.

Valida el JSON con Zod, persiste en SQLite y permite listar o consultar por id / tipo. Mismo id → 201 la primera vez, 200 al reenviar. Docker Compose y GitHub Actions.

indicadores-api

CRUD con filtros, resumen (cantidad, promedio, mín/máx por categoría) y health checks. Capas Controller → Service → Repository, ProblemDetails, Swagger y xUnit con EF InMemory.

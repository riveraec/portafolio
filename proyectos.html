01

etl-reportes

Destacado
GitHub

Pipeline ETL idempotente de movimientos/KPIs.

Lee CSV, limpia y valida con pandas, carga a SQLite y genera un resumen diario por fecha y categoría. Cada corrida es idempotente por lote (fuente): reprocesar el mismo archivo no duplica filas.

Relacionado: reportes-api

Python pandas SQLite pytest
02

reportes-api

Destacado
GitHub

API FastAPI sobre el ETL: dispara corridas y consulta el resumen.

Expone POST /runs y GET /resumen (filtros por categoría y fechas) sobre SQLite. Health check, OpenAPI/Swagger y pruebas con TestClient.

Relacionado: etl-reportes

Python FastAPI SQLite pytest

Node.js

03

eventos-api

Destacado CI
GitHub Actions

Ingesta idempotente de webhooks.

Valida el JSON con Zod, persiste en SQLite y deja listar o consultar por id / tipo. Si llega el mismo id, responde 201 la primera vez y 200 al reenviar. Docker Compose y CI en GitHub Actions.

Node.js Express Zod SQLite Docker

indicadores-api

Destacado
GitHub

API .NET 8 de indicadores con filtros y resumen.

CRUD con filtros, endpoint de resumen (cantidad, promedio, mín/máx por categoría) y health checks sobre EF Core. Capas Controller → Service → Repository, ProblemDetails, Swagger y xUnit con EF InMemory.

.NET 8 EF Core xUnit Swagger

05

auth-api

GitHub

Autenticación JWT con Spring Security.

Registro con BCrypt, login que emite JWT y GET /me protegido con Bearer token. Modo stateless, filtro JWT, JPA + H2 y OpenAPI.

Serie: productos-api → cliente-servicios-remotos

Java Spring Security JWT H2

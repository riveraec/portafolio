01 eventos-api CI

API Express para ingerir webhooks: valida con Zod, guarda en SQLite y no duplica si llega el mismo id (201 la primera vez, 200 al reenviar).

GitHub CI
Node.js Express Zod SQLite Docker SuperTest
Caso: por qué importa la idempotencia
Problema
Un emisor puede reenviar el mismo evento. Si insertas otra vez, hay doble efecto.
Decisión
Clave id + SQLite: primer POST → 201; el mismo id → 200 con el registro ya guardado.
Resultado
Reprocesar es seguro. Misma idea que en el ETL batch. CI corre npm test en cada push.
